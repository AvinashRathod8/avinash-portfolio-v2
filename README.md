# Avinash Rathod — Portfolio V2

A production-ready Next.js portfolio draft for Avinash Rathod. This project is intentionally separate from the existing GitHub Pages portfolio so the current site remains untouched during development and testing.

## Stack
- Next.js App Router
- TypeScript
- CSS (custom, no UI framework)
- Responsive design

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Production test

```bash
npm run build
npm start
```

## Deployment

Recommended first deployment: Vercel connected to a new GitHub repository. Do not replace the current `My-Portfolio` repository until the new site has been reviewed and tested.

## Before launch

- Replace/approve project case studies with only verified project details.
- Add a professional headshot if desired.
- Verify resume PDF and public contact details.
- Verify all links and mobile layouts.
- Configure custom domain after production QA.
